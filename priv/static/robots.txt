# ============================================================
# robots.txt — Bot access policy
# ============================================================
# Four groups: blocked, search + AI answer engines, link
# unfurlers, archives. Anything unlisted is denied at the bottom.
#
# A group's rules apply to every `User-agent` line directly above
# them (RFC 9309), so each rule set is written once per group
# rather than once per bot. The per-bot copies this replaced had
# already drifted out of sync with the router.
#
# Paths are listed twice — bare and as `/*/<path>` — because the
# public pages are also served under a locale prefix: `/fr/blog`
# is the same page as `/blog`, and `Disallow: /blog` does not
# match it.
# ============================================================

# Search engines and AI answer engines — ALLOW (with limits)
# -----------------------------------------------------------
# The answer engines are the point of this group. gamend is a
# developer tool: a large share of "how do I run a game backend"
# style questions are now asked of ChatGPT and Perplexity rather
# than typed into a search box, and those crawlers index in order
# to cite, not to train. Blocking them removed this site from
# that surface entirely.

# Google. The subtype crawlers are named explicitly rather than
# left to inherit the Googlebot group, so the policy is readable
# from this file alone.
